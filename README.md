Gobble Dash — The Great Thanksgiving Escape: an original 2D canvas turkey escape game. Gobble the turkey runs 1000m from the farmyard through the barn to the kitchen, chased by Farmer Bramble, jumping fences, hay bales and rolling pumpkins, sliding under swinging carving knives, leaping the oven, grabbing corn (+50) and golden feathers (+150), and hiding in haystacks when the farmer closes in. Title screen, live HUD (score, distance, 3 lives, dash cooldown, farmer-proximity warning), caught/escaped end screens with restart, synthesized WebAudio sound, 3 stages with rising speed and new hazards, 6 obstacle kinds, 4 screenshots of real gameplay.

## Run it

```sh
node serve.ts
```
